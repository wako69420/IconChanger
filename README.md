# Icon Changer

Icon Changer is a native macOS application that allows you to seamlessly customize the icons of your files, folders, and applications with a single click or drag-and-drop. Designed for Apple Silicon and modern macOS, it integrates directly with the best icon repositories on the web.

## Features
- **Drag & Drop Simplicity**: Drop any `.app`, folder, or file into the app, and drag an image directly from the web to instantly change its icon.
- **Native macOS Design**: Built entirely with SwiftUI, featuring translucent sidebars, vibrant materials, and an integrated native web browser.
- **Save Your Favorites**: Configure a custom Download Directory to permanently archive any icons you apply or download.
- **Built-in Icon Browsing**: Browse macOSIcons, Icons8, Flaticon, IconFinder, and more directly within the app without needing a separate web browser.

## Documentation
1. Launch the app.
2. Drag the file or application you want to modify and drop it into the **Target** zone on the left sidebar.
3. Browse the built-in repositories on the right.
4. **Drag any image** from the web view directly over the Target zone to apply it instantly, OR click the download button on a `.icns` file to have it applied automatically.
5. If the icon doesn't update in your Dock immediately, click the **Refresh Dock** button.
6. To revert an icon to its system default, click **Restore Original Icon**.
